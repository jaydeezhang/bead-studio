# 豆豆工坊

双击 `index.html` 即可离线打开。CSS、JavaScript、图标和音效都包含在文件里。界面使用浏览器和操作系统自带字体。

新标签页首次打开时，80 个光标会在约 3 秒内拼装整个工作台。颜色、轮廓、光效和飞行路径每次都会变化。右上角可以重播，播放中可点「跳过动画」或直接操作。启用系统「减少动态效果」时会直接进入画板。

- **图纸闯关**：选爱心、星星、蘑菇、猫脸、咖啡杯或小房子。可以随时关闭底影。放错时会亮一下，仍可以继续拼。图纸要求的位置全部放了豆子后结算，正确的珠子越多、放在图纸外的珠子越少，准确率越高。95% 起 3 星，70% 起 2 星，其余 1 星。同一关按准确率优先记录最佳成绩，准确率相同时取用时更短的成绩。清空画板可重新挑战。
- **自由创作**：支持 16×16、29×29、32×32。拖动画笔可连续放豆，右键或长按可擦掉。吸管可取已放珠子或当前可见底影的颜色。油漆桶按上下左右填充同色连通区域。每张板最多撤销或重做 60 步，清空也可撤销。
- **触屏和键盘**：双指缩放，同时移动两指可平移。也可以选平移工具拖动画板。鼠标按住空格可拖动视角。聚焦画板后可以用方向键定位、Enter 落珠、Delete 擦除。用 Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。
- **熨烫与保存**：点「熨烫」看珠子融合成像素画。下载可选透明底或白底，PNG 每格为 20×20 像素。点保存图标可存入「我的作品」。再次落珠会回到可编辑的珠子状态。
- **图片转图纸**：从本机选图，指定板面和最多颜色数。保留图片比例，透明区域留空。生成后直接进入自定义关卡。重新导入会替换上一张自定义图纸。

草稿、自定义颜色、作品、最佳成绩和音效设置存于当前浏览器的 localStorage。清理浏览数据、隐私模式或移动 HTML 文件可能影响访问原有记录。需要长期留存的作品可下载 PNG。

多光标效果使用原生 Canvas 和 JavaScript 实现，编排灵感来自 [swarm-cursors](https://github.com/DhvanilPatel/swarm-cursors) 与 [Joel Califa 的 Swarm](https://califa.github.io/swarm-site/)。
